# ADR 0005: a read-only MCP server

Status: accepted (2026-11-12). Checked against https://modelcontextprotocol.io (the specification index; the page listing versions returned 404, the navigation data listed the versions).

- Released MCP spec versions seen: 2024-11-05, 2025-03-26, 2025-06-18, 2025-11-25, and 2026-07-28 (marked latest). The latest moves toward a stateless model (SEP-2575) and adds server discovery.
- `POST /mcp` is a stateless JSON-RPC endpoint (plain-JSON replies, no SSE, no sessions). It negotiates one of the first four versions and answers
  `initialize`, `ping`, `tools/list`, `tools/call`. It does NOT claim 2026-07-28 support; the server-card / discovery and authorization pieces are not done.
- Tools: `verify_certificate`, `search_people`. Both read-only, implemented as calls to this API's own public endpoints, with the caller's IP forwarded so
  per-IP limits apply per caller. No authentication and no write tools: nothing here can change data.
- Open: OAuth for the remote transport (API-02), resources and prompts, conformance testing against the official inspector, moving to 2026-07-28.

# Pattern note: Onboarding (PG-08)  -  SPEC-DERIVED

No moodboard. Follows the spec's onboarding wireframe and truth table (6.8).

- Chat and profile keep their own scroll regions; the page itself does not scroll on desktop.
- **Status stepper:** three stages (tell us, checks and review, verified) derived only from the server's `status` + `decision_basis` (I-9).
  Rejected shows "Needs changes" with an alert icon. Icon + text + colour always.
- **Motion:** M-03 fact capture (row slides 16 px, primary wash fades) with a reduced-motion variant (row just appears).
- Removed the tracked all-caps label on claim rows (design rule).
- **Polish later:** step connector lines, mobile layout of the stepper, Hindi copy, document-drop progress.

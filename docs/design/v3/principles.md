# Pramaan v3 design principles ("Recognition, not paperwork")

Status: proposed, awaiting owner approval. Approved visual mock: https://claude.ai/artifact/RWA3HPBYEf4FefEew7DhLF

1. **People first, system second.** The first screen shows who is in the registry and a search box, not how it is built.
2. **Celebrate achievement; proof is the backing.** Verification is shown as plain status tags, not hashes or agent names.
3. **One primary action per screen.** Get listed, find a person, or check a certificate.
4. **Value before sign-up.** Search and the live demo need no account. Ask for email only when saving, uploading a document or requesting verification.
5. **Plain words, Hindi parity.** Only one friendly character is named, Saathi. Document check, not "Lipik".
6. **Honest motion.** Every celebration fires on a real server event and only after the server status says so (I-9).
7. **Status is icon + text + colour.** Document verified (green), Public record (blue), Self-declared (grey).
8. **Navigation is floating and transparent.** No bar, no fill. Logo top-left, search and account top-right, dock at the bottom; the command palette is the real navigator.
9. **Staff tools are calm and keyboard-first.** A triage Desk, not a wall of tiles.
10. **No stock photos of people.** Member photos (with consent) or initials avatars.

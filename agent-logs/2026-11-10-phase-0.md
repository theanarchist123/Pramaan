## Findings worth knowing
- psycopg async cannot run on Windows' Proactor loop (which Playwright needs). Code fails with a clear message; tests
  that need psycopg run in their own selector loop on a thread. Linux/Docker unaffected.
- LangGraph state with objects (RunContext, dataclasses) is not safely serialisable, so state is ids/dicts and nodes
  rebuild what they need.
